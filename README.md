# Onepage Website

A React, TypeScript, and Vite portfolio website template with a home page, blog, lab, and links page.

## Run locally

```bash
git clone https://github.com/ipvesp/onepage-website.git
cd onepage-website
npm install
npm run dev
```

Run `npm run build` to generate the production site. Set `SITE_URL` to the deployment URL before building so the generated RSS feed and sitemap use the correct domain. The default `example.com` is a placeholder.

Review the sample portfolio copy and links before deploying your own version.
